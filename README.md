# Task Dashboard - Pending

A personal task management dashboard for tracking pending tasks, monthly reminders, and email integration.

## Features
✅ Pending Task Tracking
✅ Monthly Reminders
✅ Email Integration
✅ Cloud Backup
✅ Browser Notifications

## Live Demo
🌐 Access at: https://task-dashboard-pending.vercel.app

## Default Login
- Username: admin
- Password: admin

## Tech Stack
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: Firebase Realtime DB
- **Hosting**: Vercel (Frontend) + Railway (Backend)

## Local Setup

## Deployment
- Push to GitHub → Vercel auto-deploys frontend
- Backend deploys on Railway
